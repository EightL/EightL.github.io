ClipAI

Instant AI summaries & explanations for any selected text.

Status: Official 1.0 Release ✦ macOS & Windows

Why ClipAI?

Reading something dense and just want the gist - fast? ClipAI pops up exactly where you are, grabs your current clipboard text, and processes it with AI to give you a summary or explanation. No browser switching. Low friction = you actually use it.

Core Features

One Hotkey

Press once to open, again to hide. Summarize instantly from clipboard text.

Multi-Provider

Supports OpenAI, Gemini, Anthropic, Groq, Grok via OpenRouter. Bring your own keys.

Privacy First

No telemetry, no analytics. API keys stored locally only.

Custom Prompts

Use defaults or create your own summary/explanation styles.

Themes & Markdown

Light, Dark, Midnight, Forest, Rose, Amber, High Contrast. Flexible Markdown modes.

Document Sessions

Create sessions for books, papers, and long reads. Add title/author, keep notes, and improve summary context.

What's New in ClipAI v1.1.0

Auto Copy Selection

ClipAI now grabs your selected text automatically—no manual copy needed.

Text Appearance Controls

Adjust font family, size, weight, line height, and letter spacing for better readability.

Document Sessions

Create sessions for books, papers, and long reads. Add title/author, keep notes, and improve summary context.

Other Improvements

  • Output Control: Set custom limits for max input characters and output tokens in Settings.
  • Reset to Defaults: Restore preferences quickly while keeping your API keys and custom presets.
  • Plus: Refined popup layout, UI polish, and minor bug fixes.
