Markov Decision Processes (MDPs)

Completed: May 18, 2025

The mathematical framework underlying reinforcement learning problems.

  • States, Actions, and Rewards
  • Markov Property and State Transitions
  • Policies and Value Functions
  • Bellman Equations and Optimality

Key Insight: Understanding how the Markov property simplifies the complexity of sequential decision making was critical for building intuition about how agents learn optimal behaviors.

Agent-Environment interaction in an MDP

Source: Sutton, R. S., & Barto, A. G. (2018). Reinforcement Learning: An Introduction (2nd ed.). MIT Press.

My Notes: Finite Markov Decision Processes

  • Agent ↔ Environment loop
    On each time step the agent observes a state, picks an action, then receives a reward and the next state. The complete transition dynamics are given by the probability distribution over next states and rewards.
  • States, Actions, Rewards
    State must summarize all history that matters going forward; actions are the choices under the agent's control; rewards are the single-number signals defining success.
  • Markov property
    With a well-chosen state representation, future outcomes depend only on the current state–action pair, not on earlier history, making the problem a Markov decision process (MDP).
  • Return & discounting
    The objective is to maximise expected discounted return - the sum of future rewards weighted by a discount factor between 0 and 1, balancing short- vs. long-term pay-offs.
  • Policies & value functions
    A policy selects actions. State-value and action-value functions predict the return you can expect if you start from a state (or state–action) and then follow a policy.
  • Bellman optimality
    Optimal values satisfy recursive equations relating the value of a state to the values of successor states. Any policy that's greedy with respect to the optimal value functions is guaranteed optimal.

Dynamic Programming

Completed: June 2, 2025

Solving MDPs with perfect knowledge of the environment.

  • Policy Evaluation
  • Policy Improvement
  • Policy Iteration
  • Value Iteration

Key Insight: Even though DP methods assume complete knowledge of the environment (rarely available in real-world scenarios), they establish the theoretical foundation for model-free methods that I'll use in my thesis.

My Notes: Dynamic Programming

  • What it is
    An iterative method for solving MDPs by applying backup updates until values or policies converge.
  • Value Iteration
    Starts with arbitrary state values, then repeatedly updates each state's value based on expected rewards and next‐state estimates, stopping once changes are negligible.
  • Policy Iteration
    Alternates between:
    - Policy evaluation: compute value estimates for the current policy
    - Policy improvement: update the policy to pick better actions based on those estimates
    Repeat until the policy no longer changes.
  • Why it matters
    DP gives a concrete, guaranteed-to-converge procedure for finding optimal value functions or policies, so an agent can act optimally without further planning.

Monte Carlo Methods

Completed: June 15, 2025

Learning from complete episodes of experience, without a model.

  • First-visit and Every-visit MC Prediction
  • MC Control with Exploring Starts
  • On-policy (ε-soft) and Off-policy (importance sampling) methods

Key Insight: MC methods are the first step towards learning from raw experience, freeing us from the need for a perfect environment model. The concept of learning from *complete returns* is a key difference from TD methods.

Generalized Policy Iteration (GPI) loop, which MC methods follow.

Source: Sutton, R. S., & Barto, A. G. (2018). Reinforcement Learning: An Introduction (2nd ed.). MIT Press.

My Notes: Monte Carlo Methods

  • What it is
    Model-free methods that learn value functions and optimal policies from sample episodes of experience. Unlike DP, they don't need a model of the environment's dynamics.
  • Prediction (Evaluation)
    To estimate V(s), MC methods run many episodes and average the returns observed after each visit to state s. This works because the average return converges to the expected return.
  • Control (Improvement)
    Follows the pattern of Generalized Policy Iteration (GPI). After evaluating the current policy, it's improved by making it greedy with respect to the current value function. To ensure exploration, methods like exploring starts or ε-soft policies are used.
  • Key trade-off
    MC updates only happen at the end of an episode. This means learning can be slow, but the updates are unbiased since they are based on the actual, full return. This contrasts with TD methods which "bootstrap" and update on every step.

Temporal-Difference Learning

Completed: June 21, 2025

A blend of Monte Carlo and Dynamic Programming ideas, learning from each step.

  • TD(0) Prediction for state-value estimation
  • SARSA: On-policy TD control
  • Q-Learning: Off-policy TD control
  • TD(λ) and Eligibility Traces

Key Insight: TD learning introduces "bootstrapping"—updating a guess with a better guess. This allows agents to learn online, after every single step, rather than waiting for an episode to finish.

My Notes: Temporal-Difference Learning

  • What it is & The Bias-Variance Tradeoff
    A model-free method that learns from other learned estimates (bootstrapping). It trades the high variance of Monte Carlo for some bias, as it updates on estimates, not full returns. This often leads to faster learning.
  • TD(0) Prediction
    The simplest form for policy evaluation. It updates a state's value V(S) using the reward R plus the discounted value of the next state V(S')—updating a guess with a slightly better guess.
  • SARSA (On-Policy Control)
    An on-policy algorithm that learns the value of the policy the agent is *actually following* (including exploration). The update uses the action A' the agent actually takes, leading to a more conservative or "safer" policy.
  • Q-Learning (Off-Policy Control)
    An off-policy algorithm that learns the optimal policy regardless of the agent's actions. It uses the value of the *best* possible next action (max) for its update, allowing it to learn an optimal policy while behaving exploratorily.
  • On-Policy vs. Off-Policy: A Summary
    On-policy (SARSA) learns the value of the current behavior policy. Off-policy (Q-Learning) learns the value of the optimal policy while following a different, exploratory policy.
  • Unifying MC and TD: TD(λ) and Eligibility Traces
    Bridges the gap between one-step TD (λ=0) and Monte Carlo (λ=1). It uses an eligibility trace, a short-term memory of recent state-action pairs, to assign credit from a TD error to all recent, eligible steps. This allows for more efficient learning, especially with delayed rewards.

Function Approximation

Completed: June 26, 2025

Extend value estimation to very large or continuous state spaces by using a parametric function in place of a lookup table.

  • Why a table of every state value is infeasible when |S| is huge or continuous
  • Using gradient-descent and semi-gradient updates for both TD and Monte Carlo targets
  • Linear function approximation: defining feature vectors and weight updates
  • Batch methods and least-squares approaches (LSTD, LSPI)
  • Empirical convergence behaviour of TD vs. MC
  • Off-policy divergence issues, including Baird’s counterexample
  • Gradient-TD and emphatic-TD methods that ensure convergence off-policy

Key Insight: Replacing the value table with a parameterised function trades exactness for scalability. With linear features and on-policy updates, semi-gradient TD converges reliably, but combining function approximation, bootstrapping, and off-policy learning can lead to divergence. Methods like Gradient-TD or emphatic-TD fix this by optimising a true gradient objective.

My Notes: Value Function Approximation

  • Problem setup
    Instead of storing V(s) in a table, define a function v̂(s,w) with parameters w and adjust w to minimise the mean-squared error between v̂(s,w) and the true value function.
  • Linear approximation
    Use a feature mapping x(s) and set v̂(s,w)=x(s)ᵀw. For Monte Carlo targets, update w ← w + α (G−v̂) x(s). For TD(0), use the TD error δ = r + γ v̂(s′,w) − v̂(s,w) and update w ← w + α δ x(s).
  • Incremental vs. batch
    • TD(λ) trades bias and variance by blending multi-step returns, with equivalent forward and backward formulations. • LSTD computes the weight vector in one shot by solving Aw = b, requiring O(d²) storage but giving fast, stable solutions.
  • Control
    Semi-gradient SARSA or Q-learning can be applied over features x(s,a). On-policy updates remain stable; off-policy updates can diverge unless you use gradient-corrected algorithms.

Policy Gradient Methods

Completed: July 20, 2025

Learning a parameterized policy that can select actions without consulting a value function. A value function may still be used to learn the policy parameters, but it is not required for action selection.

  • REINFORCE Algorithm
  • Actor–Critic Methods
  • Policy Gradient Theorem
  • Average-reward (differential) formulations
  • Continuous action parameterizations (e.g., Gaussian)

Key Insight: Policy gradient methods directly optimize a parameterized policy, making them ideal for continuous action spaces and complex control. Monte Carlo PG is unbiased yet high-variance, whereas actor–critic leverages TD-style bootstrapping to reduce variance at the cost of bias—often yielding more efficient and scalable learning.

My Notes: Policy Gradient Methods

  • What it is
    • Directly learn a parameterized policy π(a | s, θ) that maps states to action probabilities.
    • Maximize a scalar performance measure J(θ) via gradient ascent on parameters: θt+1 = θt + α ∇J(θt).
    • Differs from action–value methods (e.g., Q-learning, SARSA) that learn action-values first and then derive the policy.
    • When both policy and value approximations are learned, the setup is called actor–critic (actor = policy; critic = value function).
  • Prediction (Evaluation)
    • J(θ) can be the start-state value in episodic tasks or the average reward rate in continuing tasks.
    • The Policy Gradient Theorem gives an exact expression proportional to ∇J(θ) that does not require differentiating the state distribution—key for practical estimation.
    • REINFORCE is a Monte Carlo policy-gradient method that estimates the gradient using complete returns Gt and updates policy parameters after episodes.
    • Subtracting a baseline (e.g., v̂(St, w)) reduces variance without adding bias.
  • Control (Improvement)
    • Improve the policy by updating θ in the direction of the estimated gradient (gradient ascent).
    • REINFORCE with baseline learns both the policy and a state-value baseline to reduce variance.
    • Actor–critic replaces Monte Carlo returns with a bootstrapped value estimate (the critic), enabling online, incremental learning with lower variance (but some bias).
    • One-step actor–critic uses the TD error δt = Rt+1 + γ v̂(St+1, w) − v̂(St, w) as the reinforcement signal; can be generalized to n-step and eligibility-trace variants for both actor and critic.
    • For continuing tasks, formulate objectives to maximize the average reward rate using differential value functions and TD errors.
  • Key trade-off
    • Flexibility & expressiveness: Handles continuous actions naturally and can represent complex policies; can approach deterministic behavior by driving preferences.
    • Bias–variance: REINFORCE is unbiased but high variance and slower for long episodes; actor–critic introduces bias via bootstrapping but cuts variance and supports fast, online learning for complex, continuing problems.

Psychology and Neuroscience

Completed: July 28, 2025

Connections between reinforcement learning and the science of learning and the brain. How animals learn from prediction and control, and how neural mechanisms implement RL-like computations.

  • Classical vs. Instrumental Conditioning
  • Blocking, Higher-Order Conditioning
  • Dopamine as TD Error
  • Neural Actor–Critic Architecture
  • Habits (model-free) vs. Goal-directed (model-based)

Key Insight: RL offers a unifying computational lens for animal learning and brain function: prediction via classical conditioning, control via instrumental conditioning, and neural implementation via dopamine-driven TD errors and actor–critic–like circuits.

My Notes: Psychology and Neuroscience

  • How Animals Learn (Psychology)
    • Prediction (Classical Conditioning): Animals learn to predict rewards (US) from earlier cues (CS); actions do not affect reward arrival.
    ◦ Blocking: Prior prediction from one cue prevents learning about a new cue presented alongside it; TD learning explains this via lack of surprise (zero TD error).
    ◦ Higher-Order Conditioning: Cues that predict primary reward become secondary reinforcers; TD bootstrapping propagates predictive value backward to earlier cues.
    • Control (Instrumental Conditioning): Actions have consequences (Thorndike).
    ◦ Law of Effect: Behaviors followed by satisfaction become more likely; trial-and-error learning.
    ◦ Exploration: Necessary to discover rewarding actions, mirroring RL exploration strategies.
    ◦ Delayed Reinforcement: Eligibility traces and TD value functions act as conditioned reinforcers to bridge action–reward delays.
    ◦ Cognitive Maps: Environment models parallel psychological cognitive maps for planning and prediction beyond immediate rewards.
    ◦ Habits vs. Goal-Directed: Habits are automatic, stimulus-driven (model-free); goal-directed behavior is planful and flexible (model-based). Behavior often shifts from goal-directed to habitual with experience.
  • How Brains Do It (Neuroscience)
    • Dopamine as a TD Error Signal: Phasic dopamine matches TD error dynamics—bursts for unexpected rewards, shifts to predictive cues after learning, dips when expected rewards are omitted (Schultz et al.). This supports the reward prediction error hypothesis.
    • Neural Actor–Critic Architecture: Ventral striatum (critic) learns value; dorsal striatum and prefrontal cortex (actor) select actions; dopamine TD error trains both systems.
    • Reward‑Modulated STDP: Dopamine-gated, timing-dependent plasticity resembles policy updates with contingent eligibility traces linking actions to delayed rewards.
    • Brain Regions for Habits and Goals: Dorsolateral striatum supports model-free habits; dorsomedial striatum, prefrontal cortex, and hippocampus support model-based, goal-directed planning.
